# עולמות

אפליקציית PWA לניהול רעיונות, מטרות ומעקבים במבנה בועות אינטראקטיבי.

## הפעלה

```bash
npm install
npm run dev
```

## Supabase

1. הריצו את `scripts/init-db.sql` ב-SQL Editor.
2. העתיקו `.env.example` ל-`.env` ומלאו:

```
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

בלי משתנים אלה האפליקציה נשמרת בשקיפות ב-LocalStorage.

## מסכים

- מפת עולמות: קנבס בועות עם גרירה, כניסה פנימה ו-FAB.
- מוקדי פוקוס: קיבוץ לפי סטטוס וצבע, כולל החלפת צבע גלובלית.
- החלקה ימינה/שמאלה בין המסכים.
